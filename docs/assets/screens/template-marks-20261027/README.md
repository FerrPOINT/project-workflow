# Общие знаки и метки в SSR Workflow

Codex IAB, 2026-10-27. Настоящие Jinja content fragments и три product renderers
с принятым SSR export Base; callbacks синтетические. Ни Workflow backend,
ни API/Auth, credentials или установленный стенд не используются. Сохранение
и удаление в source-сцене отключены.

- [Light, 375 px](marks-light-375.png).
- [Dark, 1920 px](marks-dark-1920.png).
- [Gray, 2560 px](marks-gray-2560.png).

Фактическая ширина iframe проверена дважды перед full-page снимком. Белая
область вне мобильного iframe относится к QA-документу. Все три снимка
просмотрены. Проверены 12 сочетаний тем и ширин, клавиатура и focus, границы
popup, 36 доступных имён иконок, длинное имя и выбор второго одинакового имени
по собственному ID. Малый IconMark получает 28 px, SVG — 17 px из Base tokens.
Для белой подложки glyph сохраняет цвет текста своей темы.

Это доказательства оформления и локального поведения общей композиции;
они не подтверждают публикацию, серверное сохранение или runtime-приёмку.
