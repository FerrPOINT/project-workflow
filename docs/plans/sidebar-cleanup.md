# Очистка навигации

Совместимый UI-патч для установленного pdlc1 ef2cf9e, без обновления миграций и backend. Глобальная ссылка «Фазы» удалена; фазы доступны из выбранного процесса с его workflow_id и namespace_id. Несохранённый процесс не имеет перехода к фазам. Задачи обозначаются как выполнения, определения агентов — роли и профили в «Служебном». Статическая подпись «Сервис работает» удалена. Пункт /settings «Команды CLI», его расположение в блоке управления, страница и команды не меняются.

Функции, данные, API и права доступа сохраняются. Служебная группа свёрнута по умолчанию, раскрывается при прямом входе и допускает ручное сворачивание. На desktop и mobile используется одно состояние. Проверки: точные ресурсы при одинаковых названиях, старые ссылки, Back/Forward, all-projects scope, доступность, роли и narrow/wide UI.

Область навигации берётся из текущего URL: единственный `project_scope=all`
переносится во внутренние ссылки и ссылки каталога сервисов после подготовки
документа. Путь `/settings`, разметка пункта CLI и его шаблон остаются прежними;
область добавляется только в параметры перехода. Внешние ссылки вне каталога,
загрузки и некорректные URL не переписываются. Legacy-ссылки без области и
неоднозначный параметр не получают область автоматически.

Возврат из фаз в редактор сохраняет подтверждённые workflow, namespace и режим.
Смена пространства, которая сбрасывает выбранный workflow, также сбрасывает его
режим. Эти правила не меняют API, привязки, миграции и историю процессов.
