# Общая геометрия логотипа оболочки

Workflow потребляет размер 40 px из Base SSR через класс base-shell-mark. Локальная ширина свёрнутого сайдбара связана с высотой хедера. Канонические SSR-ресурсы экспортируются из exact Base SHA, который записан в .base-ui-revision. API, данные, авторизация и серверная логика не меняются.

Проверка: экспорт без drift, тесты шаблонов и браузерная геометрия на мобильной, планшетной и широкой ширине.
